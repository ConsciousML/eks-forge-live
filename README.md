[EKS Forge](https://eks-forge.readthedocs.io/latest/) is an open-source platform for building and operating [EKS](https://aws.amazon.com/eks/) clusters.

This repository deploys the [catalog](https://github.com/ConsciousML/terragrunt-template-catalog-eks)'s stacks across `staging` and `prod`, with CI/CD.
